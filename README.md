# DSA Tracker (Console App)

A file-based, read-only console application to manage and view your solved DSA problems with metadata, code, and complexity details — built with C# and SOLID principles.

## 📂 Features

- 🔍 View all solved problems
- 📄 See problem metadata: title, difficulty, URL, date
- 💡 View your code and Big-O complexity
- ✅ Pure file-based (no DB), great for Leetcode or GFG tracking
- 🧱 Structured with Clean Architecture

## 🚀 Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Visual Studio 2022+ (or JetBrains Rider)

### Run the App

```bash
git clone https://github.com/anjotadena/DSATrack.git
cd DSATrack
